# OpenCode shoutout

OpenCode stood out because it is open source, terminal-native, and model-agnostic. Those qualities mattered more to me than being tied to a single model provider, proprietary environment, or editor-first workflow.

Its clean CLI and inspectable architecture made it easy to understand how a modern coding agent behaves. It also gave me a strong, credible reference point while developing and benchmarking Metis. Claude Code and Codex offer deep integrations with their respective model ecosystems, while Cursor and Kilo Code focus more heavily on editor-based workflows. OpenCode was the closest match for my preference for flexible, transparent developer tooling that can work with different models.
