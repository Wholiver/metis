Agent

管理当前 Agent 会话及后续新会话使用的模型、推理和上下文默认值。

连接 Server 后可修改 Agent 设置。

模型

当前模型立即切换当前会话，并保存为后续新会话的默认模型。
思考等级控制推理深度并保存为默认值。可选等级由当前模型决定；切换模型时会自动调整到新模型支持的最近等级。

上下文

自动压缩（持续策略）上下文接近模型上限时自动生成摘要。它是持续生效的默认策略，不会立即压缩；立即执行请用“交互 → 手动压缩”。

常规

界面语言统一设置 Desktop 动态状态与 Agent / TUI 语言；Desktop 状态立即生效，Agent / TUI 重载后生效。

交互

控制 Agent 忙碌期间消息如何进入当前运行，以及上下文何时压缩。

连接 Server 后可修改交互设置。

消息队列

Steering 模式仅处理 Agent 正在生成时发送的“立即指导”。逐条：每次交付一条并等待响应；全部：把已排队指导一次性交付。
Follow-up 模式仅处理等待 Agent 本轮结束后再发送的消息。逐条：一问一答；全部：本轮结束后一次性交付全部排队消息。

上下文维护

立即压缩（一次性操作）马上为当前会话生成一次上下文摘要，不会改变上方“自动压缩”开关。说明文字只影响这一次摘要。

会话

管理当前会话、历史会话、分支和导入导出。

连接 Server 后载入会话信息。

当前会话

会话名称正在载入统计…
复制最后回复只复制最近一条已完成的 Agent 文本消息；不会复制思考过程、工具输出或仍在生成的内容。
克隆会话复制当前分支截至当前位置的完整历史，创建新会话；原会话保持不变。
新建会话创建完全空白的会话。当前会话不会删除，仍可从“恢复其他会话”返回。

历史与分支

恢复其他会话切换到另一个已保存的会话文件；列表排除当前会话，不创建副本。
从消息分叉复制所选消息之前的历史并创建新会话，再把该消息放回输入框供修改；原会话保持不变。
会话树在同一会话文件内移动到其他历史节点，不创建新会话；列表排除当前节点。

传输与分享

导出会话HTML 适合阅读、不能恢复；JSONL 保留完整会话结构，可通过“导入会话”恢复。
导入会话复制 JSONL 为新的本地会话并立即切换。当前会话不会被删除，HTML 文件不能导入。
分享会话把会话 HTML 上传为私密 GitHub Gist。需要已安装并登录 gh；“私密”仅表示不公开列出，持有链接者仍可访问。

账户与安全

管理项目代码资源是否允许载入，以及 Agent 调用模型时使用的 Provider 凭据；二者互不替代。

连接 Server 后载入账户状态。

项目权限

当前项目可信状态只控制项目级扩展、Skills、Prompts、主题等代码资源是否载入；不控制 Server 网络连接。保存后需重启 Agent 才完全生效。

Provider 登录

OAuth使用 Provider 订阅账户授权。无需填写 API Key；登录流程会打开浏览器或显示设备验证码。
API Key为内置或已注册 Provider 保存独立 API Key，不修改 Provider Base URL。
自定义 Base URL添加并管理多个 OpenAI-compatible Provider。模型可自动获取、从列表选择或手动输入。
模型列表（可多选）
移除已保存凭据只删除 Metis 本地凭据；环境变量、云端登录状态和 models.json 不会改变，因此 Provider 仍可能继续可用。

连接

管理 Desktop 与 Metis Server 的连接；Agent 设置通过此连接同步。

通常不需要修改 Desktop 默认启动并连接本地 http://127.0.0.1:4096。仅在连接远程 Server 或使用自定义端口时更改。
