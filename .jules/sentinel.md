## 2025-02-12 - Insecure Temporary File Creation Fixed
**Vulnerability:** Temporary files were created in shared directories (like `os.tmpdir()`) using highly predictable naming schemes (e.g. `Date.now()` or static strings like `"session.html"`). This enables symlink attacks (CWE-377) where an attacker could pre-create a symbolic link with the expected name, forcing the application to write to or overwrite arbitrary files with the privileges of the user running the app.
**Learning:** Avoid using `Date.now()`, `Math.random()`, or static strings to generate file names in shared temporary directories. Even combined, `Date.now()` and `Math.random()` do not provide sufficient entropy to prevent brute-forcing or race condition attacks in shared spaces.
**Prevention:** Always use cryptographically secure random identifiers (e.g. `crypto.randomUUID()` or `crypto.randomBytes()`) when creating temporary files or directories in shared spaces, and/or use `fs.mkdtemp` with a secure prefix when creating directories.
